📖 Smelter Log User Manual

1. Data Ingestion & Status Mapping

  • Template Aggregation: Combines facilities from CMRT, EMRT, and AMRT by Smelter ID (CID).
  • RMAP Audit Matching: Cross-references against official lists to assign status:
    • Conformant: Includes latest audit date, cycle, and re-audit status.
    • Active: Facility is actively participating in the audit program.
    • Standard (-): Listed in templates without active RMAP audit records.
  • Revision Tracking: Preserves delisted facilities as REVISION with Removed status.

2. Cloud Pipeline & Storage

  • Central Database: Stores the consolidated master records in Google Spreadsheet Cloud DB.
  • Automated Ingestion: Processes large datasets in chunks (500 rows) to ensure reliable sync without timeouts.

3. Live Dashboard & Analytics

  • Real-Time Sync: Click 🔄 Reload to fetch the latest cloud snapshot immediately.
  • Visual Distribution: Displays live charts for RMAP Audit Status Breakdown and Mineral Scope Distribution.

4. Search, Backup & Export

  • Multi-Column Search: Instant keyword filtering across all columns (Facility Name, Country, CID, etc.).
  • Drive Backup: Click ☁️ Backup to create a timestamped copy in Google Drive.
  • Excel Download: Click 📥 Export to download the currently filtered view as an .xlsx file.
